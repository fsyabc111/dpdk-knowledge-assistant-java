## 检查过程中被发现的真实缺陷（已全部修复）

1. **建档脚本一次只报一个失效引用**，改为收集全部后一次输出，才暴露三条坏引用：符号在所引范围之外、路径不在来源清单、行号偏移一行。
2. **事实数一度 23 项**，超过任务书为单篇设定的 22 项：合并两条同属"实现重复"的事实回到 22 项，未放宽上限。
3. **内容筛查误报**：`payload[0]` 被"数字方括号"规则命中。该规则本意是拦 RAG 式编号引用，故改为只拦独立出现的 `[数字]`、
   排除数组下标；这是提高精度，不是放宽对引用形态的拦截。
4. **证据文本含全零 IPv4 字面量**：按筛查规则属需复核项，改写为等价的中文表述，**筛查规则本身未放宽**。
5. **复制来的证据生成器残留第二批的待确认清单**，且切片边界处理有误导致语法错误（`}FOOTER` 粘连）；修正后重建。
6. **防覆盖**：`build_manifest.py` 属一次性建档脚本，重跑会覆盖后续对清单的修订；已在 README 标注不可重跑，并把它的校验逻辑固化进检查脚本
   （第二批曾发生过一次同类误操作）。
