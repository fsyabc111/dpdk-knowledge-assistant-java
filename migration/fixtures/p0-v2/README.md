# p0-v2 等待动态补验

本版本用于关闭P0两轴审查的S1/S2/S3/S4与S-01/S-03。p0-v1修订2黄金与manifest保持原样。

当前仅完成纯内存修复，正式长测结束前不运行app或连接PG。动态采集通过后，`freeze --fixture p0-v2` 才能创建新黄金与manifest；候选没有写黄金入口。

新trace包含一次非秘密业务列初态、每个HTTP/事务case逐表实际removed/added行、可重建的前后计数与完整终态。消息正文仅存字段指纹和字节数，临时输入仅存在/长度/来源/时限；不保存凭据、令牌或其hash、源码或原始上游输出。金额、unknown/NULL、扣次、分数、权限树、job与引用顺序逐值比较。

源码标记按冻结基线+版本在运行时确定性生成；实际输入sha256与持久化值断言相同。code_hash/input_hash不归一化，即使全部关联值一致替换也必须失败。

检索raw排序/分数纳入trace；当前为exact，不启用观察性1e-12容差。引用round4与业务计分保持exact。COMP003批准安全差异独立保留，不改写Python黄金。
