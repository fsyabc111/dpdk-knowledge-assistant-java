## 决策与接口

公开构造：`IndexService(DataSource,TransactionRunner,RetrievalSettings,EmbeddingConfig,ConfigurationFingerprint,ClockPort,IndexBatchEmbedding,IndexUsageSink,int embeddingBatchSize)`。

- `scan(SourceSettings)->SourceSnapshot`、`plan(SourceSnapshot)->IndexPlan`、`ingest(SourceSettings|IndexPlan)->IngestResult`、`activeRelease()->String`、`health(String)->IndexHealth`、`publish(expectedActive,PreparedIndex)->PublishReceipt`、`rollbackChecked(String)`。
- `SourceSettings(Path knowledgeConfig,Path dpdkRoot,Path assistantRoot,Path workingDirectory)`。真实 scan 在读文件前固定 active，`SourceSnapshot(String expectedActive,List<IndexNode>)` 传给 plan；另有单参 nodes 合成构造。并发发布后旧快照被 CAS 拒绝。
- `IndexBatchEmbedding.embed(List<String>,UsageCore.UsageRecorder)->List<Vector1024>`；主 Agent wiring 将既有真实 client/ModelUsageLedger 适配到该边界。服务逐批 clamp 1..10，数量/维度/finite/非零均验证。
- `IndexUsageSink.flush(UsageCore.UsageRecorder)`：finally 执行，失败前账与 CAS 失败账保持；写账异常按 Python 告警降级。主线适配复用价格/开关与 UsageLedgerStore。
- `PreparedIndex/IndexNode` 消费共享正式 DTO。scan id/embedding 可空；plan 给 id；复用节点 embedding 为空；changed 嵌入后有向量。配置复用 `IndexConfigurationFingerprint`，未改 EmbeddingPort。
- 同根来源以 YAML 首项归属，最长 root 优先；Python path 各段/code point 排序；先 realpath 再处理 symlink/..；POSIX反斜杠身份保留。切块Unicode/CRLF/行号/metadata均对照Python黄金。
- deleted 与 Python 一致：旧 id 不在新成员的数目，正文/metadata更新换 id 也计入；旧物理节点不删除。无新 DDL/自动建表，无真实源缺失时的静默漏扫。
- SnakeYAML SafeConstructor 编译验证通过，沿用已有传递依赖；是否显式直接声明由主 Agent 决定。
