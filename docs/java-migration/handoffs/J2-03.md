## 决策与接口差异

1. **新端口**（J2-04 消费）：`assignment.catalog.AssignmentCatalogPort`（submissionSnapshot / getAssignment / bestScore / isPastDeadline），受理分值与汇总动态分值两口径的分界在接口 javadoc 与 evidence/J2-03/dual-score-scope.md 固化。无契约文件改动（contracts/** 归集成者；如需登记进 transaction-ports.json 请集成者评估——本端口是包内 public 接口，未动契约版本）。
2. **求值顺序**：assignments.py 守卫是依赖形式（401 → 404 门禁 → 422 体），与 admin.py（422 先于门禁）相反，源注释显式声明；已按源实现并以 operator+空体=404 断言（evidence 登记）。
3. **CSV Content-Type 实现路径**：`utf-8-sig` 非 JVM 字符集，Spring MediaType 拒绝解析；导出端点直接 `HttpServletResponse.setHeader` 写原始头，wire 字节与 Python 一致（MockMvc 逐字节断言通过）。
4. **golden 归一化映射**：仅 assignment.id（identity 双射）与 created_at/updated_at（进程级顺序微秒，跨进程不可复现，正则形态断言）两类；deadline/last_submitted_at/错误 detail/CSV 字节全部逐值或逐字节。非覆盖分支按 pydantic v2 惯例输出并登记（golden-diff.md §有意差异）。
5. 沿用已登记差异族：int 字符串宽松转换拒绝（J2-02 AdminPydanticBody 同口径）；Jackson 拒绝 NaN/Infinity（J2-01）。
