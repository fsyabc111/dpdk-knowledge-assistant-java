## 接口与接线

- `ProductChatService(RagTaskService,AdmissionGate,SessionService,ChatTaskExecutor,ChatSettings,ClockPort)`；始终装配Bean，模型/检索缺失的新首发503，probe命中的历史重放不因上游缺失被阻断。
- `startExplain(principal,sessionId,requestId,question,explain,Runnable beforeAdmission)`；回调只在probe miss后执行，用于确定性会话预建。`checkRateLimit(subject)`与普通chat共桶；讲解controller先限流，startExplain不再重复扣分钟桶。
- `ChatTaskExecutor`构造器见源码；`setExplainResolver(explain::resolve)`由主Agent装配，purpose固定解释、双派生和可信DB查证由J3-04 resolver执行。普通chat不能传purpose绕过。
- `setUsagePolicy(boolean,Map<String,UsageCore.ModelPrice>,String)`：默认记录开/空定价/空版本；`UsageCore.parsePrices(raw)`供共享装配消费冻结环境。首发/恢复/摘要模型用量均保留未知null语义，失败不伪造0。
- `TaskTemporaryInput`四字段消费公共契约；模型版本元数据来自AgentSettings，恢复执行源优先使用任务寄存，终态清理交task事务。
