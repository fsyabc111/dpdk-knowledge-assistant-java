### 归因与最小接口

离线读取冻结golden和matrix full03实际trace的case68，精确比较 `business_delta.tables.upstream_usage_records.added` 的kind/stage/source/call_count，命令已退出1：expected含embedding/query_embed/cache_hit/0、llm/rewrite/cache_hit/0及planner两行；actual仅planner两行。历史trace只读，不能改成绿色。新PG采集与整条链复验归主Agent/matrix窗口，尚未执行。

根因是 `ChatTaskExecutor` 到 `PgReleaseReader` 只传query，后者 `EmbeddingPort.embed`、rewriter装配 `model.chat(...,null,"query_rewrite")` 丢失请求recorder。新增：

```java
PgReleaseReader.searchPinned(snapshot, input, limit, UsageCore.UsageRecorder usage);
QueryRewritePort.rewrite(original, conversationContext, UsageCore.UsageRecorder usage);
PgReleaseReader.QueryEmbeddingClient.embed(String input, ModelUsageLedger ledger, String stage);
```

旧2/3参数检索、纯rewriter/lambda与6参reader构造器保留；生产富装配支持7参reader和配置型rewriter。`RetrievalUsage` 显式桥接底层真实ledger，保留tokens/unknown、实际attempts与stage；不填无来源的upstream行，不使用ThreadLocal。缓存只保存字符串/向量，不保存request recorder。命中与同key合并者记cache_hit、calls0、tokens/duration NULL；本地规则记local。富配置缓存key分别为(endpoint/model/prompt/query)与(endpoint/model/embedding_query)，TTL600s/max512，跨实例共享；无配置纯构造器保留隔离，防不同lambda互相污染。

源语义区别：embedding loader抛错不缓存；rewrite的实际LLM失败被捕获并返回heuristic，正常返回的fallback按Python外层缓存保留，失败账本仍unknown+实际attempts。followup是真实独立调用，不因后续rewrite命中缓存而省略。

`RetrievalWiring` 允许仅注入外部 `QueryEmbeddingClient` callback，默认仍用真实 `OpenAiCompatibleEmbeddingClient.embedTexts` 和其ledger；matrix可返回固定1024向量且不写usage，生产reader/caches/命中审计保持真实。对应冻结case58首轮固定vector provider无usage行，case68真实缓存命中才有零调用行，不能用真实HTTP调用后删账模拟。
