## 决策与接口差异

1. **FormalSubmissionPort 字段补全需求（登记，不阻塞）**：冻结 record `SubmittedSource(protocol, codeText, fileName, originalBytes)` 已够用（source_origin 由 fileName!=null 判别）；`SubmitReceipt(submissionId, score)` 作为 `submit()` 投影，完整响应经包内 `SubmitOutcome`。无需改契约。
2. **超时语义映射（J1-02 端口模型内的登记差异，沿用）**：Python asyncio.wait_for 到期即 `grading_timeout`(504)（含已提交后超时）；Java 经 Deadline——提交前到期 → 端口 NOT_SUBMITTED/`harness_deadline_exceeded` → 本卡折算 `grading_timeout`(504)；提交后失败 → UNKNOWN/`harness_unavailable`(502)（Python 该面=传输异常 502；「已提交后挂起」Python 给 504、Java 给 502，两者均不重发、配额/成绩账面一致）。
3. **成绩写入端口类型**：配额依赖 J2-05 实现类 `UsageCounterStore.checkAndCountDaily`（独立事务、失败计数保留——Python `check_and_count_daily` 同款）；契约接口 `QuotaParticipant` 只有事务参与版，未扩接口。
4. **Python 数值化语义（或链/float()/int()/list()）逐条复刻**：score 走 HALF_EVEN（PythonScore.roundToInt 共用实现）；畸形可数值（"abc"）抛 500（ValueError 面）；results 非空对象取键序列表（Python list(dict)）；payload protocol 覆盖存储协议、best 恒按请求协议。
5. **accepted_assignment 时间形态**：deadline/assignment_updated_at 为 Python str(datetime)（空格分隔，与 J2-03 golden 冻结一致）；accepted_at 为 isoformat。均由受理快照 Instant 渲染。
6. **500 异常渲染缺口（平台层，不私改）**：MockMvc standalone 下未捕获异常不成响应（Python 500 返回纯文本 "Internal Server Error"）；归属 ApiExceptionHandler 平台契约范围，P2 集成评估。
7. **JSON NaN/Infinity 字面量**：Java Jackson 拒绝 → 422 "request body must be valid JSON"；Python json.loads 容忍 → 后续 pydantic 422 数组。J2-01 已登记同族差异，本卡沿用。
8. **TaskGradeParticipant 未实现（非目标内）**：聊天任务评测成绩（rag_task_jobs/rag_requests 联动）归 J3-01；本卡只交付正式提交路径与成绩只读端口（SubmissionRecordReader）。
