## 有意差异与边界（按基线记录，不静默修复）

- 会话删除后 pending 行**不可取消**：cancel_task 占位消息 FK 失败整笔回滚（Python 同形缺陷保留，恢复输入保留至 24h 兜底）；`maintain` 的 dangling session_id 清理属运维卡范围，未在本卡实现。
- rag_requests 时间写入用 ClockPort.nextSessionIso()（严格递增微秒）替代源的裸 wall now()——格式同形、避免同微秒碰撞，字典序比较语义不变。
- 心跳/孤儿宽限/TTL 等运行参数入 TaskSettings（源常量同位，测试可注入短值）；heartbeat loop 为 daemon 线程，装配启动由集成者接线。
- 进程内注册表替代 asyncio 单线程语义处一律显式锁/原子段（注册锁、句柄锁、订阅快照段、终态段），未用裸 ConcurrentHashMap 替代。
