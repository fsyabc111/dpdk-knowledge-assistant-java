## 决策与接口差异

详见 `evidence/J2-05/integration-pending.md`，要点：

1. **IP-J205-1（阻塞）**：冻结契约 `MessageInput(content)` 字段不足，
   `SessionPort.appendUser` 无法表达 sessionId/role/metadata；适配器按登记抛出，
   全量能力在 `SessionService.appendMessage`（参与 caller 事务，已测试）。
   请求集成者补 MessageInput 字段（最小变更请求已写明）。
2. **IP-J205-2（P3 接线项）**：活动会话删除的执行中任务处理（取消/清理/完成回写
   组合）按任务卡登记 integration_pending，归 J3-01 组合验收，不得写成已通过。
3. `QuotaExceedException` 语义固化请求（429 映射 + Retry-After）；
   `checkAndCountDaily` 保留源"失败计数留存"现状并登记有意差异
   （Python 抛 HTTPException，Java 抛领域异常由端点层转换）。
4. 求值序按 FastAPI solve_dependencies 固化：认证 401 → 参数 422 → 门禁 404 →
   业务；internal 维护端点参数 422 先于 key 403/503。
5. 时间渲染：timestamptz 读取统一归一 UTC（源测试会话时区为 UTC；确定性增强）；
   storage_bytes 为物理字段，单卡归一化断言（>0 + 精确 session_count），
   字节级由 P2 差分 suite 统一比对（同 J2-02 模式）。
