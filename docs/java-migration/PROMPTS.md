# 可复制的Agent提示词

这些提示词用于用户新建的会话，不会自动创建或启动任何Agent。把 `<...>` 替换为实际值；范围与授权写入STATUS。默认按阶段验收，后续用户明确改变授权范围时以用户最新指令为准。

## 1. 主Agent启动（用户准备实施P0时复制）

```text
你是这个Java迁移项目的主Agent。工作目录：
/Volumes/study/code/new_project/dpdk-knowledge-assistant-java

目标：按已准备的迁移规划，把DPDK教学助手主后端迁到Java；React、PostgreSQL和独立teaching_harness保留。
我现在只授权P0：冻结基线/契约/数据策略并建立合成fixture和Python差分oracle。允许在独立测试环境内安装必要开发依赖、运行本地替身和测试；不读取或改写原数据库，不调用真实模型/评测，不启动原部署，不推送或发布。P0完成后向我交付证据并等待下一阶段授权。

先读根AGENTS.md、docs/java-migration/START_HERE.md和STATUS.md，再按需读PLAN/DECISIONS及J0任务卡。
核对当前目录和Git状态；如果还没有Git，只报告并等待我建仓库后进行需要分支/工作树的动作，其余获准的P0盘点可以继续。

你负责范围、依赖、owner、验收和集成。允许多Agent：主Agent最多协调3个worker；每次给worker一张卡、指定路径和契约版本，使用独立上下文或完整的短任务包。
保持你的热上下文简洁：只保留当前阶段/授权/阻塞/决策/证据摘要；完整源码与日志按需检索，不接收子Agent整段日志。
任务状态仅由你更新；每次收口写handoff，换上下文前更新handoffs/MAIN.md。

先处理D01–D11中P0必须冻结的决策；已有范围内的常规技术选择给出建议并记录，确实影响目标或验收时聚焦向我确认。不得把规划建议写成已验收实现。
完成条件：J0-01/J0-02交付经审查的契约、schema/路由覆盖、外部依赖、差异策略、明确阈值与oracle正反例证据；实现/自动验证/场景/用户验收分别记录。
```

## 2. 实现worker派工（主Agent填写）

```text
你只负责任务 <JX-YY>。当前获用户授权阶段=<Px>，授权记录=<STATUS中记录>。
工作目录=<本worker绝对路径>；基线提交/manifest=<ID>；契约版本=<ID>；fixture版本=<ID>。
任务卡=<文件与标题>。先读根AGENTS.md和本任务卡，按卡片入口阅读必要源码；不要加载整个项目历史。

目标=<一句话可验收行为>。
前置任务证据=<handoff链接>。
独占可写=<精确包/文件/测试/证据路径>。
只读=<公共契约、其他worker包、原Python基线、原项目和外部依赖>。
根pom/共享配置/DDL/前端/部署变更提交接口变更请求，由指定集成者处理。

按卡片范围实现并验证；默认上游替身和专用测试PG，不使用ambient配置。遇到契约缺失、跨owner修改或新增范围时先报告受影响点，继续独立可做部分。
任务细节和完整日志写文件。交付docs/java-migration/handoffs/<JX-YY>.md以及evidence/<JX-YY>/报告，列实际命令与退出码、修改文件、未验证、回退、后续接口需求。
向主Agent只回不超过500字摘要。不要修改STATUS，不自行放行下一阶段，不把skip当通过。
```

## 3. 独立审查/验收worker

```text
你是任务<JX-YY>的独立验证worker，不是实现owner。
目录=<验证工作树>，目标构建=<ID>，契约/fixture=<ID>，授权范围=<本地替身/合成PG/指定场景>。
读任务卡、实现handoff和相关diff，按验收矩阵检查接口/权限/事务/并发与实际证据。
独占可写=<review报告和已指定测试路径>；业务代码只读。发现缺陷提供最小复现、影响与责任卡，不顺手改实现或放宽黄金样例。
不要相信历史通过数；核对验证是否针对目标构建。结果区分通过/失败/未执行/阻塞/明确不适用。
按templates/REVIEW.md落报告；给主Agent≤500字结论和证据链接。未授权真实调用、原数据库和部署均不操作。
```

## 4. 主Agent换上下文/接续

```text
接续本Java迁移任务。目录=<绝对路径>。
只先读根AGENTS.md、docs/java-migration/STATUS.md、handoffs/MAIN.md；按其中当前任务链接加载必要材料。
先核对Git/工作区、当前授权、构建/fixture、仍运行worker和文件owner；确认没有两个主Agent同时派工。
不要重跑历史所有测试或重读完整聊天。先完成handoff给出的下一步；历史证据只有对应版本有效。
若恢复点缺少关键事实，查对应文件并补交接；遇到范围改变才请求用户决定。继续保持摘要上下文和按卡分派。
```

```text
真实harness评测：<不授权 / 合成样例、环境和次数>。
生产切换：<不授权 / 具体环境及已验收手册>。
批次内自主完成；完成后交付证据，不自动追加下阶段目标。
```
